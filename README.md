# Tortas Sol - Sitio Web

**Tortas Sol** es un sitio web creado como proyecto web profesional para una pastelería artesanal.  
Desarrollado con HTML, CSS y JavaScript, este sitio muestra galerías de productos, contacto, redes sociales y secciones clave para una presencia web moderna.

---

## 📌 Características

- Diseño responsivo adaptable a móviles y pantallas grandes  
- Galería de imágenes y videos con lightbox interactivo  
- Barra de navegación con scroll suave  
- Optimización básica de SEO (robots.txt + sitemap.xml)  
- Favicons generados para múltiples dispositivos  
- Secciones funcionales: Inicio, Sobre mí, Galería, Contacto

---

## 🧰 Tecnologías usadas

- HTML5  
- CSS3  
- JavaScript  
- Git & GitHub Pages

## 📦 Contenidos del repositorio

- `index.html` → Página principal  
- `css/styles.css` → Estilos personalizados  
- `js/main.js` → JavaScript de funcionalidad  
- `assets/` → Imágenes, videos y favicons  
- `robots.txt` → Instrucciones para rastreadores web  
- `sitemap.xml` → Mapa del sitio para motores de búsqueda
